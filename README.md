# PDF Slimmer (클라이언트 전용 PDF 압축기)

> **서버 전송 없이 100% 내 컴퓨터 브라우저 메모리(RAM)에서만 안전하게 동작하는 초고속 PDF 용량 압축 웹앱**

---

## 🔒 완벽한 개인정보 및 데이터 보안
- **서버 통신 0%**: 업로드한 PDF 파일이 외부 서버, 클라우드, API로 절대 전송되지 않습니다.
- **인메모리 처리**: 파일은 사용자의 웹 브라우저 메모리 안에서 JavaScript 엔진을 통해서만 처리되며, 브라우저 창을 닫으면 메모리에서 즉시 소멸합니다.
- **기업 대외비/계약서 안심 처리**: 민감한 개인정보나 기밀 문서도 보안 걱정 없이 안전하게 다이어트할 수 있습니다.

---

## 🚀 실행 방법 (무설치 / 서버 불필요)
Node.js, Python, 웹 서버 등 **어떠한 프로그램도 설치할 필요가 없습니다.**

1. 폴더 안의 **`index.html`** 파일을 마우스로 **더블 클릭**합니다.
2. 기본 웹 브라우저(Chrome, Edge, Whale, Safari, Firefox 등)에서 즉시 실행됩니다.

---

## ⚙️ 압축 모드 안내

| 프리셋 | 특징 | 권장 사용처 | 예상 절감률 |
| :--- | :--- | :--- | :--- |
| **스마트 균형 (추천)** | 텍스트 선명도를 유지하면서 최적의 JPEG 인코딩 적용 | 일반 보고서, 포트폴리오, 공문서 | **약 60% ~ 80% ↓** |
| **최대 압축 (초경량)** | 해상도와 압축률을 극대화하여 용량을 최소화 | 이메일 첨부용, 포털/정부 사이트 업로드 용량 제한 시 | **최대 90% ↓** |
| **고화질 보존** | 고해상도(DPI)를 유지하며 미세 노이즈만 정리 | 고품질 인쇄, 도면, 사진집 | **약 30% ~ 50% ↓** |
| **텍스트/벡터 무손실** | 글자를 래스터화하지 않고 PDF 메타데이터 및 스트림만 정리 | 순수 텍스트 문서, 전자 서명 문서 | **약 5% ~ 20% ↓** |

> **💡 꿀팁: 흑백(그레이스케일) 문서 변환 토글**  
> 컬러가 필요 없는 스캔 영수증, 계약서, 공문서 등은 세부설정의 **[흑백 변환]**을 활성화하면 용량이 추가로 20~30% 더 줄어듭니다!

---

## ✨ 주요 기능
- **드래그 앤 드롭 & 다중 파일 처리**: 여러 개의 PDF 파일을 한 번에 끌어다 놓아 순차적으로 일괄 압축
- **실시간 프로그레스 바**: 각 페이지별 렌더링 및 압축 진행률을 실시간 시각화
- **용량 절감률 비교**: 압축 전 용량 vs 압축 후 용량 및 절감 퍼센티지 한눈에 비교
- **내장 미리보기 (Preview) 기능**: 다운로드 전에 브라우저 모달 창에서 압축된 화질과 페이지를 즉시 확인
- **개별 및 일괄 다운로드**: 개별 파일 다운로드 및 완료된 파일을 한 번에 묶는 **전체 ZIP 다운로드** 지원
- **현대적인 다크 글래스모피즘 UI**: 눈이 편안하고 직관적인 프리미엄 디자인
